# React003 — фронтенд WBSHOP

React 18-приложение на Create React App. В `src/` выделены страницы, feature-модули, API-сервисы, контекст пользователя, таблицы и хуки.

## Разделы интерфейса

- авторизация и регистрация;
- товары, типы и группы товаров;
- загрузка и синхронизация данных;
- финансовые отчёты WB и накладные расходы;
- CRM-кампании и рекламные расходы;
- цены и API-ключи;
- пользовательские настройки.

## Команды

```powershell
npm install
npm start
npm run build
npm test
```

`package.json` задаёт proxy на `http://localhost:5000`. API-вызовы используют `/api/...`; авторизация передаётся как Bearer JWT из `localStorage`.

## Правила изменений

- Сохранять существующий контракт с Node API либо одновременно менять клиент и сервер.
- Для новых API-вызовов использовать единообразную обработку статусов, ошибок и токена.
- Не хранить ключи маркетплейсов в исходниках; локальный `.gitignore` исключает секретные файлы.
- Для финансовых таблиц проверять даты, локаль, пагинацию и формат чисел.
- Для изменений UI проверять авторизованный и неавторизованный сценарии.

## Наблюдения после первичного анализа

- В проекте одновременно используются `fetch` и `axios`; при новых изменениях желательно выбрать единый подход или документировать границу.
- Встречаются варианты имён файлов с разным регистром и расширениями, поэтому новые импорты нужно проверять на точное совпадение пути.
- Тестовое покрытие просмотренных пользовательских файлов не обнаружено; перед крупными изменениями стоит определить минимальные smoke-тесты.
