# Инструкции для React003

- Это клиентская часть WBSHOP на React 18/Create React App.
- Перед изменением страницы изучить соответствующий API-сервис и серверный маршрут.
- Не переносить секреты маркетплейсов в клиентский код.
- Все защищённые запросы должны передавать Bearer-токен и корректно обрабатывать истёкшую авторизацию.
- Сохранять существующие маршруты и русскоязычные сообщения, если задача не требует их изменения.
- После изменений в сборке или маршрутизации запускать `npm run build`; для логики компонентов запускать релевантные тесты.
- Не анализировать `node_modules`, `build`, coverage и локальные секреты.
